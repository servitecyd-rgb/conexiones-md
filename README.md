# Conexiones MD — Taller especializado de reparación móvil

Sitio web desarrollado con Astro para Conexiones MD, Urachiche, Yaracuy, Venezuela.

## Identidad y enfoque
- Estética de taller electrónico: negro grafito, naranja eléctrico y acentos azul neón.
- Portada con fotografía real de una placa electrónica del taller.
- Galería de trabajos reales: diagnóstico de placas, microsoldadura, centros de carga, equipos abiertos y pruebas.
- Servicios para iPhone y Android.
- Formulario de consulta inicial que prepara un mensaje para WhatsApp.
- Contacto directo por WhatsApp: +58 412 0565259.

## Ejecutar localmente
1. Instala Node.js 20 o superior.
2. En esta carpeta ejecuta `npm install`.
3. Ejecuta `npm run dev` y abre la dirección local que indique Astro.

## Antes de publicar
- Confirmar horario comercial y términos exactos de garantía.
- Añadir reseñas reales de clientes (no se han inventado testimonios).
- Revisar el contenido y las fotografías finales.
- Ejecutar `npm run build` para validar la compilación.

El formulario ofrece una orientación inicial; el diagnóstico y presupuesto definitivos se confirman al revisar físicamente el equipo.
